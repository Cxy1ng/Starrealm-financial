## 二、 设计特异性判定 (Design Specificity Verdict)

- **主观审视**：
  `Home.vue` 的视觉语言（现代玻璃卡片、Bento Grid、流光绿色状态点）质感很在线，也能看出针对中文用户做了深度本地化（时段问候、农历生肖）。但**功能架构依然带着一点通用模板的痕迹**——尤其是全量展示历史大总账、分类进度条与饼图并存这几处，更像是为了“凑页面丰富度”而堆砌图表，没有完全站在一个“每天都要打开看一眼的个人财务仪表盘”的真实使用场景去思考。
- **静态扫描**：
  通过源码审视发现：存在图表重复请求、ECharts 图表固定写死 `380px` 高度未做响应式高度适配、部分深色模式写死在 JS 中。

---

## 三、 整体印象 (Overall Impression)

**底子很好，颜值很高，但“中看不中用”的细节还不少**。  
用户打开财务首页，第一眼最想知道的永远是：**“我这个月花了多少？这个月还剩多少预算？最近几天的钱花在哪了？”**  
而现在的首页却在告诉用户：“你建号以来一共花了多少钱（累计总支出）”，并且把同一组分类占比先用进度条画了一遍，又用饼图画了一遍。把冗余去掉、把“本月/本年”时间切换加上，它的实用性会立刻翻倍。

---

## 四、 做得好的地方 (What's Working)

1. **温润的人文细节**：
   顶部根据时间段智能切换问候语（早安/午安/夜深了），结合农历与生肖日历，让冷冰冰的记账软件有了生活的温度。
2. **生动的数值跳动体验**：
   借助 VueUse 的 `useTransition` 实现了数字跳变动画，配合 Element Plus 的 `el-statistic`，进门时资产沉淀的动态感非常舒服。
3. **安全闭环处理极其坚决**：
   首次登录的强制密码修改弹窗做了完全不可穿透的遮罩阻断，并且提交成功后彻底清理 Session Cookie 并强制退出，逻辑非常缜密。

## 五、 核心问题与改进建议 (Priority Issues)

### 🔴 [P1] 核心指标缺乏时间周期筛选（累计全量 vs 本月财务）
- **为什么重要**：个人记账核心是“以月度为生命周期”的预算与流动性管理。全量累计数据（比如累计收入几十万）日常看没有指导意义，用户看不到当月的收支进度。
- **怎么改**：在 Bento 卡片组右上角增加轻量时间胶囊切换：`本月 (默认)` / `今年` / `全部历史`。后端联动接口按周期汇总。
- **推荐命令**：`/impeccable shape` 或 `/impeccable layout`

### 🔴 [P1] 进度条列表与 ECharts 饼图完全重合冗余，页面下半部分臃肿
- **为什么重要**：第 80~119 行的“分类进度条”与第 121~134 行的“ECharts 环形图”，从数据源到信息表达 100% 相同，属于典型的无效认知负荷，而且如果分类多了，两边卡片会严重高低不齐。
- **怎么改**：二合一！将进度条与环形图融合成一个卡片（左侧环形图占比，右侧紧凑展示 Top 5 分类及金额），或者用小 Tab 切换展示形式。
- **推荐命令**：`/impeccable distill`

### 🟡 [P2] 核心数据卡片与图表完全不可下钻交互
- **为什么重要**：仪表盘不仅是用来“看”的，更是“跳板”。当用户看到“本月支出异常多”或者饼图里“餐饮占了 50%”，下意识的动作是点击进去查账。但目前点击任何卡片或扇区都毫无反应。
- **怎么改**：给 Bento 卡片和 ECharts 扇区添加 `@click` 事件，带上对应的参数（如 `type=支出&category=餐饮`）跳转到账单页。
- **推荐命令**：`/impeccable delight`

### 🟡 [P2] 缺乏新用户（零数据）的导入引导状态
- **为什么重要**：新用户刚进系统时，账户结余和收支都是 ¥0.00，空荡荡的，体验很挫败，不知道第一步该干嘛。
- **怎么改**：当检测到流水为 0 时，顶部 Banner 的主按钮变成醒目的「导入我的微信/支付宝对账单」，一键唤醒刚做好的向导弹窗。
- **推荐命令**：`/impeccable onboard`

### 🟢 [P3] 装饰性英文噪音与文字层级微调
- **为什么重要**：卡片上的 `NET BALANCE`、`TOTAL INCOME`、`TOTAL EXPENSE` 属于纯装饰无意义英文，占地方且增加视觉杂讯。
- **怎么改**：干掉英文标签，改成有业务价值的微标签，比如「较上月 -8.5%」或直接省掉让界面更干净。
- **推荐命令**：`/impeccable polish`

## 六、 画像红旗测试 (Persona Red Flags)

- **Alex (高频老记账用户)**：
  - *红旗*：每次打开都只能看全量历史大账，看不到本月剩余额度；想要看餐饮明细无法点击饼图下钻；记账必须跳转路由页面，不能在首页弹窗搞定。容易弃用回到 Excel。
- **Jordan (初次使用的新手)**：
  - *红旗*：刚注册进来看见三个 ¥0.00 和一堆空白饼图，页面没有主动提示他“可以先去微信导一份对账单进来”，停滞在第一步。
- **Sam (无障碍与屏幕阅读用户)**：
  - *红旗*：ECharts 饼图完全依赖 Canvas 绘制，未提供表格或文本无障碍替代描述；农历日期计算的行缺少语义标题。

## 七、 待实施路线图规划

1. **第一期（核心可用性）**：
   - 为 Bento 卡片加入 `本月 / 今年 / 历史` 切换；
   - 增加卡片与 ECharts 点击跳转账单明细筛选下钻。
2. **第二期（排版降噪）**：
   - 整合分类进度条与环形图为单个高密度模块；
   - 移除无意义的英文装饰小标签。
3. **第三期（新手引导与联动）**：
   - 空数据时无缝唤起账单智能导入弹窗。
